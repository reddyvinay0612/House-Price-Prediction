Methodology & Research Highlights

This system implements a zero-leakage pipeline adhering to peer-reviewed regression methodologies:

  • Target Normalization: Applied \(y_{log} = \ln(1 + \text{SalePrice})\) to eliminate positive skewness and stabilize variance.
  • Outlier Filtering: Removed severe non-arms-length transactions (GrLivArea > 4000 sq ft with SalePrice < $300k).
  • Domain Feature Synthesis: Engineered TotalSF, TotalBath, HouseAge, RemodAge, and TotalPorchSF.
